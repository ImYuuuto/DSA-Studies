# Data Structures and Algorithms in TypeScript

This is a side project I use to test my skills while learning data structures and algorithms (DSA). I implement each data structure from scratch using TypeScript.

## Purpose

- Practice data structures and algorithms
- Strengthen my TypeScript skills
- Build each data structure from scratch

## Getting Started

Install the dependencies:

```sh
npm install
```

Compile the TypeScript project:

```sh
npx tsc
```
